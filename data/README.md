# Data Directory

This directory holds the raw and processed data for the `lol-worlds-analysis` project. Because these match datasets are large, **raw data files are ignored by Git** and are not stored directly in this repository.

## 📁 Structure

data/
├── README.md       # This file
├── raw/            # Unmodified match data CSVs (ignored by git)
└── processed/      # Intermediate or final outputs generated by local scripts (ignored by git)


## 📥 How to Get the Raw Data

To run the SQL scripts and Python notebooks locally, follow these steps to download the required source data:

1. Go to the [Oracle's Elixir website](https://oracleselixir.com/).
2. Navigate to the **Downloads** tab.
3. Access their linked **Google Drive**.
4. Download the match CSV files for the years **2020 through 2025**.
5. Place the downloaded CSV files into the `data/raw/` directory.

## ⚙️ Note on "Processed" Data

Unlike projects that rely on static cleaned CSVs, this project handles data processing dynamically using **PostgreSQL views and materialized views** (built via the scripts in the `sql/` directory). As a result, no processed data files are required in `data/processed/` to run the analysis—your database handles the transformations on the fly.
